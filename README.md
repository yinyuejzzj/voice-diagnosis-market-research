# 工业声纹诊断项目 · 市场调研与客户定位

针对「AI + 工业声纹诊断」方向的市场调研工具集：从公开招标平台采集真实中标公告，据此判断哪些行业真的在买单，再结合竞品与客户决策因素定位目标客群。

> 说明：本项目为实习期间的工作产出。任务书、报告与分析底稿均随仓库公开，文件中不含公司名称与个人信息。

## 这个仓库解决什么问题

工业设备预测性维护（声纹/振动监测）是一个技术先行、需求分散的赛道。判断「哪类客户真的会付费」是商业化最前置的问题。常见做法是看市场规模报告，但报告口径宽、包含大量未落地项目。本项目改用**已发生的中标公告**作为需求侧证据：

- 只统计已成交、有明确采购方和中标金额的公告，避免把预算和规划当成需求
- 按采购方行业归类，看出哪些行业在真实付费、单价在什么区间
- 结合设备停机损失、产线自动化程度等维度给客户打分，输出优先攻的行业排序

## 方法

**1. 采集**

关键词覆盖 12 组（声纹监测、声纹诊断、振动分析 设备监测、预测性维护、声学监测 工业等），目标平台包括中国招标投标公共服务平台、中国政府采购网、标找找及地方公共资源交易中心。脚本对请求做了礼貌延迟，抓取失败时输出人工采集指引，保证在反爬环境下流程仍可走通。

**2. 归类**

按 `config.py` 中的行业关键词规则，将公告归入电力、风电、钢铁、化工、轨道交通、矿山、制造、核电、水泥建材、石油天然气 10 个行业；同时用正则从公告正文提取中标金额（万元）。

**3. 评分**

两套打分：一是按行业维度打分（停机损失、产线自动化程度、AI 接受度、设备价值、合规压力，权重合计 1.0）；二是客户落地的五维打分模型，用于在候选客户之间做排序。评分项与权重全部集中在配置文件中，换项目只需改配置。

**4. 竞品**

对 6 家头部厂商做结构化对比：成立时间、团队背景、融资阶段与投资方、核心技术路线、产品形态、标杆客户。用于判断自身方案的差异化空间。

## 结果

- 采集到 2024–2026 年真实中标公告 27 条，逐条附来源链接，可回溯核验
- 核电、电力（火电/水电）、风电在停机损失与合规压力两个维度上得分最高，被列为优先行业
- 头部厂商已占据电网与轨交的高价值场景，差异化空间集中在钢铁、化工、水泥建材等停机损失中等但改造预算受限的行业

## 复用方式

换一个赛道时，只改 `config.py`：`KEYWORDS`（搜索词）、`INDUSTRY_KEYWORDS`（行业归类规则）、`COMPETITORS`（竞品清单）、`SCORING_DIMENSIONS` / `INDUSTRY_SCORES`（评分维度与权重）。其余脚本无需改动。

## 运行

```bash
pip install requests beautifulsoup4
python python_scripts/scraper_bidding.py   # 采集招标数据
python python_scripts/analyzer.py          # 输出行业评分与竞品对比
```
